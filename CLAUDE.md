# Dragon Dictionary

A personal web app for planning, researching, writing and presenting YouTube videos for the channel **Forest Dragon**. The full concept lives in `docs/CONTEXT.md`; read it before working. The Next.js app is in `frontend/`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `SuperPing44/dragon_dictionary`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: glossary in `docs/CONTEXT.md` §8, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
